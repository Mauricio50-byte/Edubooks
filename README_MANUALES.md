## 📖 Cómo Usar Esta Documentación

### Escenario 1: Nuevo Usuario
1. Lee la **Introducción** del Manual de Usuario
2. Sigue la sección **Primeros Pasos**
3. Ve a la guía específica de tu rol
4. Consulta **FAQ** si tienes dudas

### Escenario 2: Nuevo Desarrollador
1. Lee la **Arquitectura** del Manual Técnico
2. Sigue **Configuración del Entorno**
3. Explora **Estructura del Proyecto**
4. Revisa **API REST** y **Base de Datos**

### Escenario 3: Administrador de Biblioteca
1. Lee **Funcionalidades por Rol** (Manual de Usuario)
2. Estudia **Guía para Administradores**
3. Familiarízate con **Gestión de Préstamos**
4. Aprende **Gestión de Sanciones**

### Escenario 4: DevOps/SysAdmin
1. Lee **Arquitectura** (Manual Técnico)
2. Revisa **Autenticación y Seguridad**
3. Estudia **Despliegue y DevOps**
4. Configura **Mantenimiento y Monitoreo**
